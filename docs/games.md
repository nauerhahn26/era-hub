# Games

Open Games from the home screen, or visit `/games/`. Games ships with the
core installation. When a computer already has an explicit app selection,
enable Games in Settings → Apps & navigation; that selection is preserved.

Fashion Studio, Four in a Row and Number Tiles run locally without an
account or subscription. Progress is stored in this browser on this computer.
Clearing browser storage removes it; it is not shared through Drive.

## Fashion Studio

Start with Make clothes, or resume the current draft. Choose garment shape,
sleeves, colour, pattern and detail through large option cards. Looking at an
option leaves the preview unchanged until that option is selected. Decorations
use prepared positions, so no dragging is needed. Undo reverses an edit.

Style the model with bottoms, shoes, hair and model choices, then save the
look in the collection. The collection holds three outfits. Editing a saved
look makes a draft copy; replacing or removing a saved look asks first.
Choose looks for the lineup and use the ordering commands to arrange them.

Set the stage and optional music, then start the show. Next model, Pose,
Encore and Pause are deliberate choices. A finished pose waits for the next
choice. Reduced motion keeps the same decisions available.

## Four in a Row

Choose a column to drop a counter. The board itself is passive. Play with
another person taking turns, or choose a computer opponent. Four matching
counters in a horizontal, vertical or diagonal line completes the game.
Undo revisits the previous turn. Restart asks before clearing the board.

## Number Tiles

Use Left, Right, Up and Down to slide the board. Equal adjacent numbers merge
once per move. A move that cannot change the board adds no tile. Undo restores
the previous board, score and random sequence. Restart asks first; reaching
2048 permits continued play.

## Gaze, touch and communication

Ordinary commands use the shared dwell setting. Exit at top-left and Talk in
the centre use twice that duration. Touch reaches the same commands. Move
away after a completed dwell before choosing again; holding the same gaze
does not repeat the action. Tracking loss freezes a partial dwell.

The black area at bottom-right has no action and is available for resting.
The models, garments and game boards are previews rather than hidden targets.
Command labels use 74-pixel text at the supported screen sizes. Passive
headings, status, collection captions and the board's column numbers have
a 44-pixel fit exception. Number Tiles numerals use the passive-display
fit exception so larger values remain inside their cells.
Talk preserves the game or show position and pauses pending computer turns,
animation and music. Navigation and hiding also stop background activity.

The partner-only area links to hosted games and their setup information.
These games may need their own gaze configuration: a hosted canvas does not
inherit this app's dwell controls. Browser checks of local Games do not
establish independent use or enjoyment on a gaze device.
