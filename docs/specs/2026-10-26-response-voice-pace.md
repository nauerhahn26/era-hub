# Active response voice pace

Settings → Voice & sound → Voice offers Response voice speed on this device,
from 70 to 120 percent in whole percentages. The default is 80 percent,
reducing the normal speaking pace by 20 percent across apps. Save writes
`responseVoiceSpeed` to this hub's local `app-settings.json`, outside the Drive
mirror. Open Settings on the device being adjusted; other devices retain their
own preference. Opening Settings never writes a preference. Saving verifies
the value by reading it back before reporting success. Invalid values are
rejected before any settings are saved; missing or invalid stored values use 0.8.

Active responses generated by the hub's shared `/tts` endpoint read that local
preference for each request. Reopen an app after saving to refresh speech
already cached in its browser memory. Speed is part of
the audio cache key so earlier, faster clips cannot satisfy these requests.
Recorded book narration, songs and the local system voice retain their current
behavior. The shared speech client and frozen Chat/Games sources are untouched.

Implementation is staged only. Testing and release wait for the maintainer;
coordinate with Testing suite before shared runtime landing or publishing.
