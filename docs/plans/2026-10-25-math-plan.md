## Acceptance points for a future build

- Quantity, numeral, speech and equation agree, including zero and transitions
  through ten. There is no silent wrap, overflow, duplication or negative part.
- One completed dwell causes one action; tracking loss cannot complete one.
  Looking at passive mathematical content cannot activate a command.
- Interrupting Count stops queued narration/highlights and leaves a consistent
  mathematical state. Input is never locked behind a model or animation.
- Talk/Back/Exit work using their established meanings and hold times. Returning
  from Talk restores the quantity, parts, representation and current workspace.
- Large text, target geometry, spacing and inert corner pass at 1920×1080 and
  1280×720; actual device viewing and gaze remain a separate observation.
- Touch parity, offline rendering and speech fallback are usable. Adult-only
  controls cannot receive gaze activation. No child-facing score or countdown.
- Observation records distinguish learner action from prompt, demonstration or
  partner input; none is automatically treated as curriculum mastery.

## Research retrospective

The most consequential finding was that the latest individual school report
supports mathematical relationships and larger-number access, rather than a
design limited to early numeral recognition. Class updates also connect
structured quantities to number partners. The evidence supports those concepts;
it does not establish the ideal gaze layout. The proposal therefore keeps
access usability, interest and mathematical learning as separate questions.

## Implementation findings

Math preserves existing explicit app selections; enable it in Settings when
it is absent from the home screen. Registry-driven home tiles and shortcuts
required no new launch mechanism. The payload includes the page, state model
and arithmetic icon, and both uninstall paths know Math's shortcut name.

The first isolated payload build passed scanning and served the Math home
tile and working unit controls. It used a fresh temporary data directory on
an approved free test port and was stopped afterward. No live hub was changed.

Testing found that preserving command DOM nodes is necessary for the shared
move-to-rearm rule. It also caught the need to block input as soon as Talk is
selected, before its request completes, and retain the shared resume delay.
Both are covered by real-browser regressions.

A separate probe of actual speech transport found a shared defect: a delayed
old audio download could start after `Speech.stop()` and a newer number had
already spoken. The app's generation checks alone cannot prevent playback
inside the shared layer. The matching `era-core--wt-math` worktree contains
the independently reviewed minimal fix and four passing regressions; final
payload and gate runs must use
`ERA_WT_SUFFIX=--wt-math`. The main core checkout is untouched.

The Talk input guard also retains access to the shared Exit door while a
visible handoff request is stalled. Only math commands are ineligible during
that period; a hidden window disables the full dwell engine. A test first
reproduced the lost escape action, then verified it with real dwell.
